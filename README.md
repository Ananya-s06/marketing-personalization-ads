# Marketing Personalization & Ads Analytics

## Project Overview

This project analyzes e-commerce marketing personalization, advertising performance, customer behavior, and recommendation models using data analytics techniques.

## Tools Used

* Microsoft Excel
* SQL
* Power BI
* GitHub

## Project Objectives

* Analyze customer segments and behavior.
* Evaluate recommendation model quality and click performance.
* Analyze orders, revenue, and marketing channels.
* Measure advertising campaign performance.
* Identify opportunities to improve marketing effectiveness.

## Project Workflow

1. Data cleaning and validation
2. Excel analysis and pivot tables
3. KPI calculations
4. Power BI dashboard development
5. Business insights and recommendations

## Key Performance Indicators

* Impressions and clicks
* Click-through rate (CTR)
* Orders and gross merchandise value (GMV)
* Average order value (AOV)
* Advertising spend
* Return on advertising spend (ROAS)

## Project Deliverables

* Cleaned data
* Excel analysis workbook
* Power BI dashboards
* Business insights and recommendations
